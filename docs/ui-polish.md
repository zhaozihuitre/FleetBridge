# 舰桥界面美化建议

2026-11-06。只提建议，没有改代码。依据：正式版 0.9.30 在 1600×950 下的截图（部队、活动终端、指令、存档），以及 demo 实例里的深空 / 浅色主题、1100 宽窄屏、390 宽手机页、两个分屏的 PowerShell；另外对照了 `web/style.css`、`web/theme.js`、`web/app.js`、`web/terminal.js`。

没截到的：通知（Windows 通知、主控收到的文字通知）和页面查看面板。这两部分只按代码提了少量建议，标了「未实测」。

工作量按一个人估：S ≤ 1 小时，M 半天左右，L 1 天以上。

## 一、投入小、效果明显

### 1. 只有一页时不显示翻页条；页码点太多时收起 · S
- **现在**：活动终端只有 1 页、指令也只有 1 页时，底部仍显示「◀ 上一页 · ◆ 01/01 · 下一页 ▶」。部队页有 10~19 页时排出一长串菱形点，窄屏下挤到换行（「01/」和「19」分成两行），「下一页」被截掉。
- **怎么改**：总页数为 1 时整条隐藏；超过 7 页只显示当前页附近几个点，再加「…」，或者只显示「03 / 19」。
- **文件**：`web/app.js`（翻页渲染）、`web/style.css`。

### 2. 部队标签的数字和实际卡片数对上 · S
- **现在**：标签显示「部队 3」，翻页却有 10 页（运行中的 3 个之后是离线项目的卡片），看起来像出错。
- **怎么改**：标签写成「3 · 共 20」，或者在第一张离线卡片前加一条细分隔「以下是没在运行的项目」。

### 3. 项目名、文件夹名不用 Orbitron · S
- **现在**：部队卡片大标题、存档左栏文件夹名都用 Orbitron 全大写。这个字体很宽，长名字被截（如「QC-PMS-BACKEN…」）；「1 运行中」徽章也被挤到第二行。Orbitron 也没有小写，名字原来的大小写看不出来。
- **怎么改**：Orbitron 只留给品牌、数字和时钟（额度百分比、倒计时、T+ 计时）。名字改用 Rajdhani 或 Noto Sans SC，保留原来的大小写，字重 600~700，以免失去分量。
- **文件**：`web/style.css` 里用 `var(--display)` 的名字类选择器。

### 4. 中英双语小标签只留一种 · S
- **现在**：「LOAD 记忆负载」「DRONES 僚机」「REPOS 仓库」「QUEUE 排队中」「SAVE DATA」等每处都是英文加中文，信息量没有增加，却占了宽度、分散视线。标签页在 1700 像素以下已经只显示中文，其他地方没有跟上。
- **怎么改**：按当前语言只显示一种。英文的「装饰味」可以只留在区块大标题上（如 QUEUE、LOG），小标签一律用当前语言。

### 5. 「全部结束」不要做成最显眼的按钮 · S
- **现在**：活动终端页右上角，红色实心的「全部结束」和「全部打开」并排，而且比「全部打开」还醒目，容易误点。
- **怎么改**：改成描边或幽灵按钮，放到「⋯」菜单里或放到右边最远处。点击后的确认框里列出会结束哪些终端。

### 6. 指令记录表按列对齐 · S～M
- **现在**：目标列宽度随名字变化，后面的「主控」来源标签时左时右；项目名长的行（如一个带长文件夹名的终端）会把标签挤出边框。状态列（「已发送」）占了很宽，最右边的指令正文反而被截成一行。
- **怎么改**：
  - 用 grid 固定列宽：时间 52px、状态 120px、目标 220px（超长省略）、来源一个固定小列、正文占剩下的宽度。
  - 正文允许两行，悬停显示全文。
  - 按天加分隔（今天 / 昨天）。

### 7. 浅色主题的几处色差 · S
- **现在**：
  - 浅色下，主控终端和分屏终端的底色（#f6f6f3，偏暖）和旁边的面板（#f3f4f6，偏冷）不是一个色调，看起来像贴了一块。
  - 卡片和页面背景几乎一样，层次靠很淡的边框，区分不开。
  - 手机页的浅色下，外部会话卡片整体被调淡，名字对比度偏低。
- **怎么改**：
  - 终端底色改成和 panelDeep 同一色系。
  - 卡片加一层很轻的阴影或稍深的边框（lineHi）。
  - 手机页「外部会话」改为只调淡副信息，名字保持正常对比度。
- **文件**：`web/theme.js` 的 light、`web/m.css`。

### 8. 加上 favicon · S
- **现在**：浏览器里打开（headless 版、手机页）请求 `/favicon.ico` 得到 404，标签页上是默认图标。
- **怎么改**：用现有的舰桥图标导出 SVG favicon，再加一个 PNG 给手机的「添加到主屏幕」。

### 9. 字体打包到本地 · S～M
- **现在**：Orbitron、Rajdhani、Noto Sans SC 是从 Google Fonts 在线加载的。没网、被公司网络拦截或首次加载慢时，会退回系统字体，数字和标题的宽度跟着变，有的地方会错位。一个只在本机跑的应用每次还要连外网。
- **怎么改**：Orbitron 和 Rajdhani 的 woff2 放进 `web/fonts/`（很小）。中文不打包 Noto（太大），回退到 Microsoft YaHei UI 或系统字体，并把字号、行高按回退字体调一遍。

### 10. 终端字号可调 · S～M
- **现在**：主控终端 12px，分屏里「不是当前」的窄面板会缩到 11px，在高分屏上偏小。截图里分屏右侧的窄面板文字几乎看不清。
- **怎么改**：
  - 设一个基础字号（设置里可选 12~16，或在终端里按 Ctrl + / Ctrl −），存在本机。
  - 动态分屏缩小时不低于 12px，地方不够就少显示几列。

## 二、中等投入

### 11. 窄屏布局（1100～1400 宽） · M
- **现在**：样式里只有一条 `@media`（1700 以下隐藏标签页英文）。1100 宽时：
  - 顶部两个额度框的标题被截成「ENERGY · 5…」「RESERV…」，重置时间截成「今天 17:5」。
  - 标签页截成「活动终」，数字全看不到。
  - 搜索框只剩一点。
  - 翻页条溢出（见第 1 条）。
- **怎么改**：
  - 1400 以下：额度框只显示百分比和倒计时，重置时间放进悬停提示。
  - 1200 以下：标签页只显示中文加数字，「全军出击 / 出击 / 终端」变成图标按钮，搜索框收成放大镜按钮，点开后再展开。
  - 1100 以下：总指令台默认收起（分隔条那里已经有收起功能）。

### 12. 状态标识统一成一个组件 · M
- **现在**：一个终端的状态，同时用到菱形颜色、英文加中文文字（AWAITING · 待命）、卡片左边框颜色，还有总指令台的「情绪」（● 招手 / ● 请求授权）。几处用的词也不一样（待命 / 休眠 / 作战中 / 等授权），而且主要靠颜色区分。
- **怎么改**：做一个状态 chip，形状 + 颜色 + 文字：作战中 ▶、待命 ◆、等授权 ⚠、等回答 ?、出错 ✕。部队卡片、活动终端列表、分屏标题栏、小窗、手机页都用它，词汇统一。这样色弱也能分辨。

### 13. 部队卡片和活动终端列表的留白 · M
- **现在**：
  - 部队卡片高度固定，下半截常常空着（只有状态、负载、仓库三块）。一屏只放 2 张，3 个终端就要翻页。
  - 活动终端页 3 行之后是大片空白。
- **怎么改**：
  - 卡片高度随内容；一屏放 2×2，或者宽屏时 3 列。
  - 多出的空间显示「最近一条回答」的两三行，或者最近 5 分钟的动作（工具调用名）。
  - 活动终端行里加上次指令和已运行时长。

### 14. 存档页更紧凑 · M
- **现在**：每个会话卡片约 110px 高，一页只放 5 个（55 个会话分 5 页）。每行都有一个大的「外部终端」按钮，重复很多。左栏的文件夹名问题见第 3 条。
- **怎么改**：
  - 改成两行的列表行：时间、会话名、最后指令一行，路径一行。一屏可以放 10~12 个。
  - 「在此继续」保留为主按钮，「外部终端」收进悬停才出现的图标按钮。

### 15. 分屏面板的细节 · M
- **现在**：
  - 新开的 PowerShell，提示符出现在面板中间，上半截空白。很可能是第一次适配尺寸前已经输出了，要查一下 `web/terminal.js` 的 fit 时机。
  - 窄面板标题栏里，「POWERSHELL」用 Orbitron 占掉大半，名字和状态被截成「M··· ● 终…」。
  - 底部有一条常驻的横向滚动条。
- **怎么改**：
  - 新开终端在 fit 后再接输出，或者 fit 后清一次屏。
  - 普通终端的标题改成用文件夹名（和「名字优先」一致），类型用小图标表示。
  - 去掉不需要的横向滚动条。

### 16. 通知的样子（未实测） · M
- 主控收到的【舰桥通知】是一段纯文字，几条通知一起来时，靠肉眼分条。可以统一格式：首行「状态图标 + 终端名 + 结果」，第二行起是回答。还可以考虑让指挥中心本身对新完成或中断的终端做一次短暂高亮（卡片描边闪一下），不用一直盯着主控终端。
- 页面查看面板没有截到，这次不提建议。

## 三、投入大

### 17. 主题改为按角色定义的 CSS 变量 · L
- **现在**：`style.css` 用霓虹原版的颜色写死。切换主题时，`theme.js` 把每个颜色按最接近的霓虹色映射成新主题的颜色。新加一条规则不用管主题，这是优点；缺点是映射有时会选错角色，也没办法单独微调某个主题的某一处（第 7 条那类问题就不好修）。
- **怎么改**：把颜色改成 `--bg / --panel / --text / --accent / --state-busy …` 等语义变量，每个主题只定义变量值。可以分批改，先改最常用的二三十个选择器。
- **风险**：会影响所有主题和小窗、手机页，需要每个主题都截图回归。

### 18. 平板 / 竖屏布局 · L
- 指挥中心在 900 宽以下基本不可用（目前靠手机页兜底）。可以做一个单列布局：总指令台、部队、终端用底部标签切换，终端一次只开一个全宽的。和第 11 条的断点一起设计。

### 19. 动效和「减少动态效果」 · M～L
- 样式里没有 `prefers-reduced-motion`，霓虹主题的发光和闪烁不会因为系统设置而减弱。可以先补上这一条（S），再统一状态变化的过渡动画：卡片换状态时颜色渐变、新卡片淡入，时长 150~200ms，不做持续闪烁。

## 建议的先后

1. **第一批**（半天内）：1、2、3、4、5、8。几乎只改样式，一眼能看出变化。
2. **第二批**（一天）：6、7、9、10、11。
3. **之后**：12～15 一起做一轮「信息密度」的改版；17 等前面都稳定后再做。
